# TripFlow Android updates

This public repository only stores the `latest.json` update manifest. Android APKs are attached to GitHub Releases.

TripFlow checks these URLs on launch:

- `https://raw.githubusercontent.com/goone031/TripFlow-updates/main/latest.json`
- `https://github.com/goone031/TripFlow-updates/releases/latest/download/latest.json`

Do not put Google Maps keys, OAuth secrets, or source code here.
